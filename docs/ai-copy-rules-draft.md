## 2. Cold email rules

| Rule | Default |
|---|---|
| First email length | 60 to 110 words |
| Follow-up length | 40 to 80 words |
| Subject line | 2 to 5 words, lowercase, plain, no tricks, no "Re:" or "Fwd:" |
| Structure | Hook about them, one pain, one proof (if approved), one ask |
| Ask | One low-friction question, for example "Worth a quick chat?" Never "book a 30-minute demo" in the first email |
| Links and attachments | None in the first email |
| Format | Plain text. No images, no tracking pixels, no bullet lists in the first email |
| Opening line | Must use a real fact about the recipient or the property. Never "I hope this finds you well" |
| Tone | Peer to peer, direct, human. No hype, no exclamation marks, no jargon |
| Reading level | Grade 6 to 8. Short sentences, one idea each |
| Personalization | Use one real fact. If there is none, use the campaign hook and do not pretend to know them |
| Facts | Use only facts supplied. Never invent numbers, reviews, names or events. If a fact is missing, leave it out |
| Placeholders | Baseline copy uses `{first_name}`, `{property_name}`, `{city}`. Missing values are never guessed |

**Banned phrases:** "I hope this finds you well", "touching base", "circling back", "just following up", "synergy", "game-changer", "revolutionary", "best-in-class", "cutting-edge", "leverage", "I wanted to reach out", "quick question" (as an opener), "as per my last email".

**Spam-trigger words:** free, guarantee, act now, limited time, risk-free, no obligation, 100%, winner, urgent, click here.

## 3. Step roles

| Role | What it does |
|---|---|
| **Opener** | Hook, one pain, one ask. This is the only email that introduces GuestSquad. |
| **Follow-up** | A new angle each time. Shorter than the opener. Never says "following up". Can reference the previous email in a few words. |
| **Value add** | One useful insight or approved proof point, plus a soft ask. |
| **Breakup** | Two to three lines. No pressure. Says this is the last note and leaves the door open. |
| **LinkedIn connect** | 300 characters or fewer. No pitch. A reason to connect. |
| **LinkedIn message** | 400 characters or fewer. One question. |
| **Call script** | Opener line, reason for the call, one question, a 20-second voicemail, and a gatekeeper line. |

Each step after the first is written knowing the copy of the earlier steps, so the sequence reads as one story and never repeats.

---

## 4. Voice

**We are:** direct, calm, practical, hospitality-aware. We sound like someone who has worked a front desk.
**We are not:** salesy, pushy, corporate, hyped, or flattering.

Pairs the AI follows:
- "Guests who message after midnight often wait until morning." Not "Our revolutionary solution transforms guest communication."
- "Worth a quick chat?" Not "Let me know when you have 30 minutes for a demo."

Sign-off: the sender's own name, title and phone from their profile. No fixed company signature. No opt-out or address line is added by the AI (no regional rules are applied).

Language: English.

## 5. Pain to angle map (from the CRM's pain types)

| Pain signal | Angle the email can take |
|---|---|
| Calls | Calls go unanswered when the desk is busy |
| Reservations | Booking enquiries wait too long for a reply |
| After-hours | Nobody covers guest messages overnight |
| Check-in / Access | Late arrivals can't get in or get help |
| OTA Messaging | Messages on Booking.com or Expedia sit unanswered |
| WhatsApp | Guests message on WhatsApp and nobody watches it |
| Guest Requests | Requests slip through during busy periods |
| Front Desk Staffing | Hard to hire and keep front desk staff |
| Reviews | Reviews mention slow replies |

The AI picks the campaign's primary pain, and uses the property's own signal only if the CRM actually records it.
